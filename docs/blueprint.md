# **App Name**: Tipsy Tumble

## Core Features:

- Player Body: Create a player character using Matter.js consisting of two connected bodies: a torso and a foot.
- Self-Righting: Apply torque to the player's body to automatically return to a vertical position, simulating a tumbler toy.
- Jump/Kick: Implement a combined jump and kick action triggered by a single button. Apply vertical force to the foot to initiate the jump.
- Directional Rebound: Make the player's rebound direction dependent on their orientation. When the foot collides with the ball, apply an impulse and torque to make them somersault.
- Configurable Physics: Adjust restitution and friction to achieve the 'drunk' physics.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to convey energy and a playful feel.
- Background color: Light, desaturated blue (#D1E9F2) to create a soft backdrop.
- Accent color: A lively green (#90EE90) to draw attention to action elements.
- Body and headline font: 'PT Sans', a sans-serif for a modern look with a touch of warmth.
- Use simple, cartoonish icons to match the whimsical theme of the game.
- Implement subtle animations for jumps and collisions to accentuate the comical, tipsy effect.
